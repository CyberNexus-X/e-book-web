Day 6 — String methods

String methods text ko saaf aur badal kar dikhate hain. Yaad rakho: strings immutable hain — method naya string deta hai, purana string nahi badalta.

Phase: Beginner · Reels: 26/450 – 30/450

Code

s = " arhan KHAN "
print(s.strip())
print(s.strip().title())
print(s.upper().strip())
print("a,b,c".split(","))
print("-".join(["a", "b"]))
print("chai".replace("c", "C"))
print(" Arhan_Dev ".strip().lower())

Output

arhan KHAN
Arhan Khan
ARHAN KHAN
['a', 'b', 'c']
a-b
Chai
arhan_dev

Code ki poori detail

  • s.strip() — aage-peeche ke space hata deta hai.
  • .title() — har word ka pehla letter capital karta hai.
  • .upper() — saara text capital karta hai, par s ko nahi badalta, naya string deta hai.
  • .split(",") — text ko comma par tod kar list banata hai.
  • "-".join([...]) — list ke items ko - se jodta hai.
  • .replace("c", "C") — pehle wale letter ko naye se badalta hai.
Common mistake: s.upper() akela likhne se s nahi badalta. Likhna padta hai: s = s.upper(). Strings immutable hain, s[0] = "A" par TypeError aayega.
Khud try karo: Apne naam ko capitalize karo: pehle strip, phir title use karo.
