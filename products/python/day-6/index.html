Day 6: String Methods

Phase: Beginner · Reels: 26/450 – 30/450

Quick Answer

Day 6 covers string methods like strip(), upper(), title(), split() and replace(). Strings are immutable, so every method returns a new string instead of changing the original.

What You Will Learn

  • s.strip() removes spaces from both ends of a string.
  • .title() capitalises the first letter of every word. .upper() makes the whole string capital.
  • .split(",") breaks text at commas and returns a list of parts.
  • "-".join(["a", "b"]) joins list items with - between them, giving "a-b".
  • .replace("t", "T") returns a new string with the letter replaced.

Code

s = " arhan KHAN "
print(s.strip())
print(s.strip().title())
print(s.upper().strip())
print("a,b,c".split(","))
print("-".join(["a", "b"]))
print("tea".replace("t", "T"))
print(" Arhan_Dev ".strip().lower())

Output

arhan KHAN
Arhan Khan
ARHAN KHAN
['a', 'b', 'c']
a-b
Tea
arhan_dev

Code Explained, Line by Line

  1. s.strip() removes spaces from both ends of a string.
  2. .title() capitalises the first letter of every word. .upper() makes the whole string capital.
  3. .split(",") breaks text at commas and returns a list of parts.
  4. "-".join(["a", "b"]) joins list items with - between them, giving "a-b".
  5. .replace("t", "T") returns a new string with the letter replaced.
Common Mistake: Calling s.upper() alone does not change s, because strings are immutable. You must write s = s.upper(). Trying s[0] = "A" raises a TypeError.

Real-Life Use

Cleaning usernames, emails and form input uses strip(), lower() and title() in almost every app.

Practice Task: Take your name with extra spaces, strip it, then capitalise it with title().
