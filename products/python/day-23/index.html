Day 23 — Scope aur recursion

Scope batata hai ki variable kahan se dikhta hai: local (function ke andar) vs global (bahar). Recursion me function khud ko call karta hai — base case bhoolna RecursionError deta hai.

Phase: Intermediate · Reels: 111/450 – 115/450

Code

count = 0

def inc():
    global count
    count += 1
    return count

print(inc())

def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

print(fact(5))

from functools import lru_cache

@lru_cache
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(10))

Output

1
120
55

Code ki poori detail

  • global count — function ke andar bahar wale variable ko badalne ke liye global likhna padta hai, warna UnboundLocalError aata hai.
  • fact(n) — base case n <= 1 hai, jahan rukna hai. Uske bina recursion kabhi nahi rukega.
  • fact(5) = 5 * 4 * 3 * 2 * 1 = 120.
  • @lru_cache — purane answers yaad rakhta hai (memoization), isliye fib fast chalta hai.
  • Recursion tree/nested problems ke liye achha hai, simple loop wale kaam ke liye loop hi kaafi hai.
Common mistake: Base case bhoolna RecursionError (stack overflow) deta hai. Har recursion me pehle rukne ki condition likho.
Khud try karo: Fibonacci likho (recursion se) aur factorial ka base case samjho.
