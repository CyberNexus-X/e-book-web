Day 19 — Sets

Set sirf unique values rakhta hai, duplicates apne aap hat jaate hain. Union (|), intersection (&), difference (-) aur symmetric difference (^) se sets compare hote hain.

Phase: Intermediate · Reels: 91/450 – 95/450

Code

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)
print(a & b)
print(a - b)
print(a ^ b)
visits = ["u1", "u2", "u1", "u3"]
print(len(set(visits)))
print(set())

Output

{1, 2, 3, 4}
{2, 3}
{1}
{1, 4}
3
set()

Code ki poori detail

  • {1, 2, 3} — curly brackets me set banta hai, par khali set ke liye set() likhna padta hai.
  • a | b — union: dono ke saare unique items.
  • a & b — intersection: jo dono me common hain.
  • a - b — difference: jo sirf a me hain.
  • set(visits) — list ke duplicates hata deta hai, isliye unique visitors ginne me kaam aata hai.
Common mistake: {} empty set nahi, empty dict hai! Khali set ke liye set() likho.
Khud try karo: Do lists ke common elements nikalo (set intersection se) aur unique visitors gino.
