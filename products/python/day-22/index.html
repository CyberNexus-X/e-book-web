Day 22 — lambda, map, filter

lambda chhota, ek line wala function hai. map() har item par function chalata hai, filter() sirf wo items rakhta hai jo condition pass karein.

Phase: Intermediate · Reels: 106/450 – 110/450

Code

double = lambda x: x * 2
print(double(5))
prices = [100, 250, 400]
off = list(map(lambda p: p * 0.9, prices))
print(off)
ev = list(filter(lambda n: n % 2 == 0, range(7)))
print(ev)
names = ["Al", "Riya", "Arhan"]
print(sorted(names, key=len))

Output

10
[90.0, 225.0, 360.0]
[0, 2, 4, 6]
['Al', 'Riya', 'Arhan']

Code ki poori detail

  • lambda x: x * 2 — naam ke bina chhota function hai, x input, x*2 output.
  • map(lambda p: p * 0.9, prices) — har price par 10% discount lagata hai.
  • filter(lambda n: n % 2 == 0, ...) — sirf even numbers rakhta hai.
  • sorted(names, key=len) — naam ki lambai (length) ke hisaab se sort karta hai.
  • Naam chahiye to def likho — lambda ko variable me store karke overuse mat karo.
Common mistake: Lambda ko overuse mat karo. Bada logic ho to def se naam wala function likho, padhna aasan rahega.
Khud try karo: Prices par discount lagao (map se) aur even numbers filter karo.
