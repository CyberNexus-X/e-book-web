Day 4 — Arithmetic operators

Arithmetic operators: + jod, - ghata, * guna, / bhaag (hamesha float), // floor division aur % remainder (baki). ** power hota hai.

Phase: Beginner · Reels: 16/450 – 20/450

Code

print(7 + 2)
print(7 - 2)
print(7 * 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
print(-7 // 2)

Output

9
5
14
3.5
3
1
1024
-4

Code ki poori detail

  • 7 / 2 = 3.5 — / hamesha float deta hai, chahe answer poora hi kyun na ho.
  • 7 // 2 = 3 — // neeche ki taraf round karta hai (floor division).
  • 7 % 2 = 1 — % baki (remainder) deta hai, isse even/odd check hota hai.
  • 2 ** 10 = 1024 — ** power nikalta hai.
  • -7 // 2 = -4 — floor division neeche round karta hai, isliye -3.5 ka floor -4 hai, -3 nahi.
Common mistake: / aur // ko ek mat samjho: 10 / 2 = 5.0 (float) aur 10 // 2 = 5 (int) hota hai.
Khud try karo: Ek number even hai ya odd, ye % se check karo. Phir bill ko 4 logon me baantne ka program likho.
