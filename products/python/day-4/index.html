Day 4: Arithmetic Operators

Quick Answer

Day 4 covers arithmetic operators: + adds, - subtracts, * multiplies, / divides and always gives a float, // gives the floor of the division, % gives the remainder, and ** gives a power.

What You Will Learn

  • 7 / 2 is 3.5. The / operator always returns a float, even when the answer is whole.
  • 7 // 2 is 3. // is floor division: it rounds down to the nearest whole number.
  • 7 % 2 is 1. % gives the remainder, which is how you test even vs odd.
  • 2 ** 10 is 1024. ** raises a number to a power.
  • -7 // 2 is -4, because floor division rounds down, not towards zero.

Code

print(7 + 2)
print(7 - 2)
print(7 * 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
print(-7 // 2)

Code Explained, Line by Line

  1. 7 / 2 is 3.5. The / operator always returns a float, even when the answer is whole.
  2. 7 // 2 is 3. // is floor division: it rounds down to the nearest whole number.
  3. 7 % 2 is 1. % gives the remainder, which is how you test even vs odd.
  4. 2 ** 10 is 1024. ** raises a number to a power.
  5. -7 // 2 is -4, because floor division rounds down, not towards zero.
Common Mistake: Do not confuse / and //: 10 / 2 is 5.0 (a float) while 10 // 2 is 5 (an int).

Real-Life Use

Billing apps use // and % to split a bill, find change, and check whether a number is even or odd.
