Day 24 — try/except

try/except se errors ko handle kiya jaata hai taaki program crash na ho. Specific error pakdo — bare except se bug chhup jaata hai.

Phase: Intermediate · Reels: 116/450 – 120/450

Code

try:
    x = int("abc")
except ValueError as e:
    print("Galat input:", e)
else:
    print("No error")
finally:
    print("Hamesha chalega")

try:
    print(10 / 0)
except ZeroDivisionError:
    print("Zero se divide nahi")

Output

Galat input: invalid literal for int() with base 10: 'abc'
Hamesha chalega
Zero se divide nahi

Code ki poori detail

  • try block — wo code jo error de sakta hai.
  • except ValueError as e — sirf ValueError pakadta hai, aur e me error ka message hota hai.
  • else — sirf tab chalta hai jab try me koi error na aaye.
  • finally — error aaye ya na aaye, hamesha chalta hai (cleanup ke liye).
  • ZeroDivisionError — 0 se divide karne par aata hai, isko alag se handle kiya gaya hai.
Common mistake: Bare except: ya except Exception: pass mat likho — bug chhup jaata hai aur pata nahi chalta ki galti kahan hui.
Khud try karo: Zero division handle karo aur ek safe input banao jo galat input par crash na ho.
