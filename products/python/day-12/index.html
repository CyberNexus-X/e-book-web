Day 12 — Lists basics

List ek se zyada values ko ek jagah rakhti hai. Index 0 se start hota hai, negative index peeche se ginta hai: -1 aakhri item hota hai.

Phase: Beginner · Reels: 56/450 – 60/450

Code

nums = [10, 20, 30]
print(nums[0], nums[-1])
print(len(nums))
shopping = ["doodh", "bread", "anda"]
for item in shopping:
    print("-", item)
print(shopping[1:])

Output

10 30
3
- doodh
- bread
- anda
['bread', 'anda']

Code ki poori detail

  • nums = [10, 20, 30] — square brackets me list banti hai.
  • nums[0] = 10 (pehla), nums[-1] = 30 (aakhri) — negative index peeche se ginta hai.
  • len(nums) = 3 — list me kitne items hain, ye batata hai.
  • for item in shopping — list ke har item par ek-ek karke loop chalta hai.
  • shopping[1:] — index 1 se aakhir tak ka hissa (slicing) deta hai.
Common mistake: List ke bahar ka index maangne par IndexError aata hai: 3 items ki list me nums[3] galat hai, aakhri index 2 hai.
Khud try karo: Apni shopping list banao aur uska aakhri item print karo (negative index se).
