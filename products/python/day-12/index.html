Day 12: Lists Basics

Day 12 teaches lists. A list holds many values in one place. Indexing starts at 0, and negative indexing counts from the end: -1 is the last item.

Phase: Beginner · Reels: 56/450 – 60/450

Quick Answer

Day 12 teaches lists. A list holds many values in one place. Indexing starts at 0, and negative indexing counts from the end: -1 is the last item.

What You Will Learn

  • nums = [10, 20, 30] creates a list inside square brackets.
  • nums[0] is 10 (first) and nums[-1] is 30 (last). Negative indexes count backwards.
  • len(nums) is 3: it counts how many items are in the list.
  • for item in shopping runs once for every item in the list.
  • shopping[1:] is slicing: it returns items from index 1 to the end.

Code

nums = [10, 20, 30]
print(nums[0], nums[-1])
print(len(nums))
shopping = ["doodh", "bread", "anda"]
for item in shopping:
    print("-", item)
print(shopping[1:])

Output

10 30
3
- doodh
- bread
- anda
['bread', 'anda']

Code Explained, Line by Line

  1. nums = [10, 20, 30] creates a list inside square brackets.
  2. nums[0] is 10 (first) and nums[-1] is 30 (last). Negative indexes count backwards.
  3. len(nums) is 3: it counts how many items are in the list.
  4. for item in shopping runs once for every item in the list.
  5. shopping[1:] is slicing: it returns items from index 1 to the end.
Common Mistake: Asking for an index outside the list raises IndexError. A 3-item list has indexes 0, 1 and 2, so nums[3] is invalid.

Real-Life Use

Shopping carts, playlists and to-do lists are all lists in real programs.
