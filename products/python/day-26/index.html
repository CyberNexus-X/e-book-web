Day 26 — File handling

File handling: open() se file khulti hai, 'w' likhne (purana mitata hai), 'a' jodne, 'r' padhne ke liye. with khud file band karta hai — close() bhoolne ka risk khatam.

Phase: Intermediate · Reels: 126/450 – 130/450

Code

with open("notes_demo.txt", "w", encoding="utf-8") as f:
    f.write("Line 1\nLine 2\n")
with open("notes_demo.txt", "a", encoding="utf-8") as f:
    f.write("Line 3\n")
with open("notes_demo.txt", encoding="utf-8") as f:
    lines = f.readlines()
print(len(lines))
print(lines)

Output

3
['Line 1\n', 'Line 2\n', 'Line 3\n']

Code ki poori detail

  • open(..., "w") — nayi file banata ya purani ka content mita kar likhta hai.
  • open(..., "a") — append karta hai, purana content bana rehta hai, naya aakhir me judta hai.
  • encoding="utf-8" — Hindi/emoji text ke liye safe rehta hai.
  • with — block khatam hote hi file apne aap band ho jaati hai, close() yaad rakhne ki zaroorat nahi.
  • readlines() — saari lines ki list deta hai, yahan 3 lines hain.
Common mistake: 'w' mode file ka purana content turant delete kar deta hai. Jodna hai to 'a' use karo, warna data chala jayega.
Khud try karo: Ek notes app banao: file me lines save karo, phir unki ginti (lines count) nikalo.
