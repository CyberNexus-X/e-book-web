Day 2: Data Types

Day 2 covers the four basic data types: int for whole numbers, float for decimals, str for text, and bool for True or False. The type() function tells you which type a value has.

Phase: Beginner · Reels: 6/450 – 10/450

Quick Answer

Day 2 covers the four basic data types: int for whole numbers, float for decimals, str for text, and bool for True or False. The type() function tells you which type a value has.

What You Will Learn

  • int is a whole number, like 21. float has a decimal point, like 99.5.
  • str is text inside quotes, like "Arhan". bool is only True or False.
  • type(value) returns the type of a value, for example type(21) is int.
  • "5" is text and 5 is a number. They look alike but behave differently.
  • "5" + "5" gives "55" (text joins), while 5 + 5 gives 10 (numbers add).

Code

age = 21
price = 99.5
name = "Arhan"
is_pro = False
print(age, type(age))
print(price, type(price))
print(name, type(name))
print(is_pro, type(is_pro))
print("5" + "5")
print(5 + 5)

Output

21 <class 'int'>
99.5 <class 'float'>
Arhan <class 'str'>
False <class 'bool'>
55
10

Code Explained, Line by Line

  1. int is a whole number, like 21. float has a decimal point, like 99.5.
  2. str is text inside quotes, like "Arhan". bool is only True or False.
  3. type(value) returns the type of a value, for example type(21) is int.
  4. "5" is text and 5 is a number. They look alike but behave differently.
  5. "5" + "5" gives "55" (text joins), while 5 + 5 gives 10 (numbers add).
Common Mistake: Adding text and a number, like "5" + 5, raises a TypeError. Convert first with int("5") or str(5) so both sides match.

Real-Life Use

Data types are everywhere: prices are floats, ages are ints, names are strings, and login status is a bool.
