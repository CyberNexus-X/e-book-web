Day 2 — Data types

Har value ka ek type hota hai. int poora number, float decimal, str text aur bool True/False hota hai. type() se type check hota hai.

Phase: Beginner · Reels: 6/450 – 10/450

Code

age = 21
price = 99.5
name = "Arhan"
is_pro = False
print(age, type(age))
print(price, type(price))
print(name, type(name))
print(is_pro, type(is_pro))
print("5" + "5")
print(5 + 5)

Output

21 <class 'int'>
99.5 <class 'float'>
Arhan <class 'str'>
False <class 'bool'>
55
10

Code ki poori detail

  • age = 21 — int, kyunki isme decimal nahi hai.
  • price = 99.5 — float, kyunki decimal point hai.
  • name = "Arhan" — str, kyunki quotes me text hai.
  • is_pro = False — bool, sirf True ya False ho sakta hai.
  • type() batata hai ki value kis type ki hai.
  • "5" + "5" = "55" (text judta hai), jabki 5 + 5 = 10 (number judte hain).
Common mistake: "5" text hai, 5 number hai. "5" + 5 likhne par TypeError aata hai — pehle int("5") se number banao.
Khud try karo: Guess karo: type(3.0), type("3") aur type(True) kya honge? Phir code chala kar check karo.
