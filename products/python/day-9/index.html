Day 9: elif and Nested if

Day 9 covers elif chains and nested if. Use elif when conditions must be checked one after another, and prefer and over a nested if when two conditions must both be true.

Phase: Beginner · Reels: 41/450 – 45/450

Quick Answer

Day 9 covers elif chains and nested if. Use elif when conditions must be checked one after another, and prefer and over a nested if when two conditions must both be true.

What You Will Learn

  • In an elif chain only the first True condition's block runs; the rest are skipped.
  • For marks = 85, the 90+ check fails and the 75+ check passes, so the grade is B.
  • age > 18 and has_id requires both conditions to be True for entry to be allowed.
  • Replacing a nested if with and makes code shorter and easier to read.

Code

marks = 85
if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 60:
    print("C")
else:
    print("Fail")
age = 20
has_id = True
if age > 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")

Output

B
Entry allowed

Code Explained, Line by Line

  1. In an elif chain only the first True condition's block runs; the rest are skipped.
  2. For marks = 85, the 90+ check fails and the 75+ check passes, so the grade is B.
  3. age > 18 and has_id requires both conditions to be True for entry to be allowed.
  4. Replacing a nested if with and makes code shorter and easier to read.
Common Mistake: Multiple if and elif are not the same: every multiple if is checked separately, while an elif chain stops at the first True condition.

Real-Life Use

Grade calculators, ticket pricing and access rules use elif chains in real apps.

Practice Task: Write a leap year check: a year is a leap year if it divides by 4 but not by 100, unless it also divides by 400.
