Day 9 — elif aur nested if

elif tab use karo jab ek ke baad ek conditions check karni hon. Nested if ka matlab if ke andar doosra if — iski jagah aksar and se kaam chal jaata hai aur code saaf rehta hai.

Phase: Beginner · Reels: 41/450 – 45/450

Code

marks = 85
if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 60:
    print("C")
else:
    print("Fail")
age = 20
has_id = True
if age > 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")

Output

B
Entry allowed

Code ki poori detail

  • elif chain me sirf pehli True condition ka block chalta hai, baaki skip ho jaate hain.
  • marks = 85 par pehli condition (90+) False hai, doosri (75+) True hai, isliye B print hota hai.
  • age > 18 and has_id — dono True hon tabhi entry allowed hai.
  • Nested if ki jagah and use karne se code chhota aur padhne me aasan hota hai.
Common mistake: Multiple if aur elif ko ek mat samjho: multiple if me har condition alag se check hoti hai, elif me sirf pehli True tak.
Khud try karo: Leap year check karo: saal 4 se divide ho, par 100 se nahi, ya 400 se divide ho — to leap year hai.
