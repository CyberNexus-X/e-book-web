Day 14 — Functions

Function code ka dobara use hone wala hissa hota hai. def se function banta hai, parameters input hote hain, return value wapas deta hai. print sirf dikhata hai, return nahi karta.

Phase: Beginner · Reels: 66/450 – 70/450

Code

def square(n):
    """n ka square return karo"""
    return n * n

def greet(name):
    print("Hi", name)

print(square(4))
print(square(5))
result = greet("Arhan")
print(result)

Output

16
25
Hi Arhan
None

Code ki poori detail

  • def square(n): — square naam ka function banaya, n parameter hai.
  • return n * n — answer wapas deta hai, isliye print(square(4)) = 16 dikhata hai.
  • greet() sirf print karta hai, kuch return nahi karta, isliye result = None hota hai.
  • Docstring ("""...""") — function ke baare me chhota note hota hai, code par asar nahi daalta.
  • Function kyun? Code reuse (DRY), test karna easy aur naam se samajh aana.
Common mistake: print ≠ return: print screen par dikhata hai, return value aage ke code ko deta hai. Dono ko ek mat samjho.
Khud try karo: Ek square function banao aur ek aisa function jo naam lekar 'Hi, naam' return kare (print nahi).
