Day 14: Functions

Phase: Beginner · Reels: 66/450 – 70/450

Quick Answer

Day 14 teaches functions. def creates a reusable block of code, parameters are its inputs, and return sends a value back. print only shows something; it does not return it.

What You Will Learn

  • def square(n): creates a function named square with one parameter, n.
  • return n * n sends the answer back, so print(square(4)) shows 16.
  • A function that only prints and never returns gives None when assigned to a variable.
  • A docstring ("""...""") is a short note about what the function does.
  • Functions matter because they reuse code (DRY), are easier to test, and make code readable by name.

Code

def square(n):
    """Return the square of n"""
    return n * n

def greet(name):
    print("Hi", name)

print(square(4))
print(square(5))
result = greet("Arhan")
print(result)

Output

16
25
Hi Arhan
None

Code Explained, Line by Line

  1. def square(n): creates a function named square with one parameter, n.
  2. return n * n sends the answer back, so print(square(4)) shows 16.
  3. A function that only prints and never returns gives None when assigned to a variable.
  4. A docstring ("""...""") is a short note about what the function does.
  5. Functions matter because they reuse code (DRY), are easier to test, and make code readable by name.
Common Mistake: print is not return: print shows a value on screen, return gives it to the code that called the function. Confusing them is the most common function bug.
