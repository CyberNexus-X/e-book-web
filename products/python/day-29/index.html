Day 29: pip and Virtual Environments

Day 29 is about pip and virtual environments, not Python code. pip installs packages, and a venv gives each project its own isolated environment so package versions never clash between projects.

Phase: Intermediate · Reels: 141/450 – 145/450

Quick Answer

Day 29 is about pip and virtual environments, not Python code. pip installs packages, and a venv gives each project its own isolated environment so package versions never clash between projects.

What You Will Learn

  • python -m venv .venv creates a separate environment called .venv inside the project.
  • source .venv/bin/activate (Mac/Linux) or .venv\Scripts\activate (Windows) turns the environment on.
  • pip install requests installs the package only inside this environment, not globally.
  • pip freeze > requirements.txt saves the installed packages and versions to a file.
  • pip install -r requirements.txt recreates the same setup on any new computer.
  • deactivate turns the environment off.

Code

python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install requests
pip freeze > requirements.txt
pip install -r requirements.txt
deactivate

Day 29 is about terminal commands, so there is no Python output. Run the commands in your computer's terminal, in order.

Code Explained, Line by Line

  1. python -m venv .venv creates a separate environment called .venv inside the project.
  2. source .venv/bin/activate (Mac/Linux) or .venv\Scripts\activate (Windows) turns the environment on.
  3. pip install requests installs the package only inside this environment, not globally.
  4. pip freeze > requirements.txt saves the installed packages and versions to a file.
  5. pip install -r requirements.txt recreates the same setup on any new computer.
  6. deactivate turns the environment off.
Common Mistake: Installing every package globally makes project versions clash. Create a venv for every project.

Real-Life Use

Every professional Python project uses a venv plus requirements.txt so teammates get the same setup.

Practice Task: Create a venv for your project, install one package, and create requirements.txt.
