Day 16: Tuples

Phase: Intermediate · Reels: 76/450 – 80/450

Quick Answer

Day 16 teaches tuples. A tuple is like a list, but it is immutable: once created it cannot be changed. That makes it usable as a dictionary key and slightly faster than a list.

What You Will Learn

  • point = (3, 4) creates a tuple inside round brackets.
  • type((5)) is int, because without a comma it is just a value in brackets.
  • type((5,)) is tuple: a single-item tuple needs a trailing comma.
  • a, b = b, a swaps two values without a temporary variable, using packing and unpacking.
  • first, *rest = [1, 2, 3, 4] puts the first item in first and the rest in a list called rest.

Code

point = (3, 4)
print(point, type(point))
print(type((5)))
print(type((5,)))
a, b = 1, 2
a, b = b, a
print(a, b)
first, *rest = [1, 2, 3, 4]
print(first, rest)

Output

(3, 4) <class 'tuple'>
<class 'int'>
<class 'tuple'>
2 1
1 [2, 3, 4]

Code Explained, Line by Line

  1. point = (3, 4) creates a tuple inside round brackets.
  2. type((5)) is int, because without a comma it is just a value in brackets.
  3. type((5,)) is tuple: a single-item tuple needs a trailing comma.
  4. a, b = b, a swaps two values without a temporary variable, using packing and unpacking.
  5. first, *rest = [1, 2, 3, 4] puts the first item in first and the rest in a list called rest.
Common Mistake: The most common tuple mistake is forgetting the comma: (5) is an int, (5,) is a tuple.

Real-Life Use

Coordinates, RGB colours and database rows are often tuples, because they should not change by accident.

Practice Task: Swap two values using unpacking and explain the difference between a list and a tuple.
