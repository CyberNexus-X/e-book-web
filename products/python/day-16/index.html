Day 16 — Tuples

Tuple list jaisa hota hai, par immutable hai — banne ke baad badla nahi ja sakta. Isliye ye dict ki key ban sakta hai aur thoda fast hota hai.

Phase: Intermediate · Reels: 76/450 – 80/450

Code

point = (3, 4)
print(point, type(point))
print(type((5)))
print(type((5,)))
a, b = 1, 2
a, b = b, a
print(a, b)
first, *rest = [1, 2, 3, 4]
print(first, rest)

Output

(3, 4) <class 'tuple'>
<class 'int'>
<class 'tuple'>
2 1
1 [2, 3, 4]

Code ki poori detail

  • point = (3, 4) — round brackets me tuple banta hai.
  • type((5)) = int hai, kyunki comma ke bina ye sirf brackets wali value hai.
  • type((5,)) = tuple hai — single item tuple ke liye comma zaroori hai.
  • a, b = b, a — bina temp variable ke values swap ho jaati hain (packing/unpacking).
  • first, *rest — pehla item alag, baaki sab rest list me aa jaate hain.
Common mistake: Single item tuple me comma bhoolna sabse common galti hai: (5) int hai, (5,) tuple hai.
Khud try karo: Do values swap karo (unpacking se) aur batao list vs tuple me kya farak hai.
