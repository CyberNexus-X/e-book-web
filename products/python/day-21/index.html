Day 21 — Function arguments

Function arguments: default value, *args (extra positional, tuple me) aur **kwargs (extra keyword, dict me). Mutable default (jaise bag=[]) har call me share hota hai — ye trap hai.

Phase: Intermediate · Reels: 101/450 – 105/450

Code

def greet(name, msg="Namaste"):
    return f"{msg}, {name}"

def total(*args, **kwargs):
    print(args, kwargs)
    return sum(args)

print(greet("Arhan"))
print(greet("Arhan", "Hello"))
print(total(1, 2, 3, tax=5))

def add(item, bag=None):
    if bag is None:
        bag = []
    bag.append(item)
    return bag

print(add("a"))
print(add("b"))

Output

Namaste, Arhan
Hello, Arhan
(1, 2, 3) {'tax': 5}
6
['a']
['b']

Code ki poori detail

  • msg="Namaste" — default argument hai, na do to yehi value chalegi.
  • *args — extra positional arguments ko tuple me pakadta hai.
  • **kwargs — extra keyword arguments ko dict me pakadta hai.
  • bag=None pattern — sahi tareeka hai. bag=[] likhne par wo list har call me share hoti hai (trap).
  • Isliye add("a") aur add("b") alag-alag list dete hain, ek saath judi hui nahi.
Common mistake: def f(x, bag=[]): mat likho — wo list har call me share hoti hai. Default None rakho, andar [] banao.
Khud try karo: Ek function banao jo kitne bhi numbers ka sum nikaale (*args se).
