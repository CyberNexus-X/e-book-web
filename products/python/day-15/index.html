Quick Answer

Day 15 is the Phase 1 mini project and recap: a calculator built with a function and a dictionary of operations, and a number guessing game built with a while-style loop and conditions.

What You Will Learn

  • calc(a, op, b) takes two numbers and an operator and returns the result.
  • Division by zero is checked first, so the program returns a message instead of crashing.
  • A dictionary maps each operator to its job, using a small lambda function for each.
  • ops[op]() picks the right operation from the dictionary and runs it; an unknown operator gives 'Invalid op'.
  • The guessing game compares each guess with the secret and breaks out of the loop on a correct guess.
  • Top 3 beginner mistakes: = vs ==, forgetting int() on input(), and wrong indentation.

Code

def calc(a, op, b):
    if op == "/" and b == 0:
        return "Cannot divide by zero"
    ops = {"+": lambda: a + b, "-": lambda: a - b, "*": lambda: a * b, "/": lambda: a / b}
    return ops[op]() if op in ops else "Invalid op"

print(calc(8, "*", 5))
print(calc(8, "/", 0))
print(calc(10, "+", 5))
secret = 7
guesses = [3, 9, 7]
for guess in guesses:
    if guess == secret:
        print("Correct!")
        break
    print("Too high" if guess > secret else "Too low")
