Day 15 — Mini project + recap

Phase 1 ka mini project: Calculator (function + dict se operations) aur Number Guessing Game (while loop + condition). Yahi Day 1–14 ka recap hai.

Phase: Beginner · Reels: 71/450 – 75/450

Code

def calc(a, op, b):
    if op == "/" and b == 0:
        return "0 se divide nahi"
    ops = {"+": lambda: a + b, "-": lambda: a - b, "*": lambda: a * b, "/": lambda: a / b}
    return ops[op]() if op in ops else "Invalid op"

print(calc(8, "*", 5))
print(calc(8, "/", 0))
print(calc(10, "+", 5))
secret = 7
guesses = [3, 9, 7]
for guess in guesses:
    if guess == secret:
        print("Sahi!")
        break
    print("Zyada" if guess > secret else "Kam")

Output

0 se divide nahi

Zyada
Sahi!

Code ki poori detail

  • calc() — a, op, b leta hai: do numbers aur ek operator.
  • op == "/" and b == 0 — divide-by-zero ko pehle hi rok diya, warna crash hota.
  • ops dict — operator ko uske kaam se jodta hai; lambda chhota function hai.
  • ops[op]() — dict se sahi kaam chun kar chalata hai, galat operator par 'Invalid op' milta hai.
  • Guessing game — har guess ko secret se compare karta hai; sahi milte hi break se loop ruk jaata hai.
  • Beginner ki top 3 galtiyan: = vs ==, input() ko int na karna, galat indentation.
Common mistake: Calculator me zero se divide karna, = aur == me confusion, aur input() ko bina int() ke use karna — ye teen galtiyan sabse zyada hoti hain.
Khud try karo: Phase 1 challenge: calculator me -, / aur % bhi jodo, aur guessing game me tries ginne ka counter lagao.
