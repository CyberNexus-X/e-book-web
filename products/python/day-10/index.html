Day 10 — for loop aur range()

for loop kisi cheez par baar-baar chalta hai. range() numbers banata hai: range(5) = 0,1,2,3,4 — aakhri number (5) isme nahi aata.

Phase: Beginner · Reels: 46/450 – 50/450

Code

for i in range(5):
    print(i, end=" ")
print()
print(list(range(2, 11, 2)))
print(sum(range(1, 11)))
for i, f in enumerate(["aam", "kela"], start=1):
    print(i, f)
for i in range(1, 4):
    print(f"5 x {i} = {5 * i}")

Output

0 1 2 3 4 
[2, 4, 6, 8, 10]
55
1 aam
2 kela
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15

Code ki poori detail

  • range(5) — 0 se 4 tak numbers deta hai, 5 isme nahi aata.
  • range(2, 11, 2) — 2 se start, 11 se pehle tak, 2-2 ke step par: 2,4,6,8,10.
  • sum(range(1, 11)) — 1 se 10 tak ka total = 55.
  • enumerate() — list ke saath number (index) bhi deta hai, start=1 se ginti 1 se shuru hoti hai.
  • for loop tab use karo jab pata ho kitni baar ya kis cheez par chalana hai.
Common mistake: 1 se 10 chahiye to range(1, 11) likho, range(1, 10) nahi — end wali value kabhi nahi aati.
Khud try karo: 1 se 10 tak ka sum nikalo aur 5 ka table (table generator) print karo.
