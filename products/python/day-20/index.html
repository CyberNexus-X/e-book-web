Day 20 — List comprehension

List comprehension ek line me list banata hai: [expression for item in iterable if condition]. Chhota aur fast hai, par zyada complex ho to normal loop hi likho.

Phase: Intermediate · Reels: 96/450 – 100/450

Code

sq = [n * n for n in range(1, 6)]
print(sq)
evens = [n for n in range(10) if n % 2 == 0]
print(evens)
tags = ["even" if n % 2 == 0 else "odd" for n in range(3)]
print(tags)
d = {n: n * n for n in range(3)}
print(d)
total = sum(n * n for n in range(4))
print(total)

Output

[1, 4, 9, 16, 25]
[0, 2, 4, 6, 8]
['even', 'odd', 'even']
{0: 0, 1: 1, 2: 4}
14

Code ki poori detail

  • [n * n for n in range(1, 6)] — har n ka square lekar list banata hai.
  • if n % 2 == 0 — sirf wo items aate hain jo condition pass karein.
  • ["even" if ... else "odd" ...] — har item ke liye ek ya doosri value chunna.
  • {n: n * n ...} — dict comprehension hai, key: value ke jode banata hai.
  • sum(n * n for n in ...) — generator hai: list banaye bina total nikalta hai, memory bachata hai.
Common mistake: 3 level nested comprehension koi nahi padh payega. Complex ho to normal loop likho — readability pehle.
Khud try karo: 1 se 9 tak ke squares ki list comprehension se banao.
