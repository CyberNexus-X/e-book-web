Day 27 — with statement aur CSV

with statement context manager hai: __enter__ setup karta hai, __exit__ cleanup karta hai (error aaye tab bhi). CSV ke liye csv module use karo, newline="" ke saath.

Phase: Intermediate · Reels: 131/450 – 135/450

Code

import csv, io
buf = io.StringIO()
rows = [["item", "amt"], ["chai", 20], ["samosa", 15]]
with io.StringIO() as out:
    pass
writer = csv.writer(buf)
writer.writerows(rows)
buf.seek(0)
with io.StringIO(buf.getvalue(), newline="") as f:
    total = sum(int(r["amt"]) for r in csv.DictReader(f))
print(total)
print(buf.getvalue())

Output

35
item,amt
chai,20
samosa,15

Code ki poori detail

  • csv.writer — rows ko CSV format me likhta hai.
  • newline="" — CSV file kholte waqt zaroori hai, warna extra khali lines aa jaati hain.
  • csv.DictReader — har row ko dict banata hai, column naam se value milti hai (r["amt"]).
  • sum(...) — saare amounts ka total nikalta hai, yahan 35 hai.
  • with — file/buffer ko khud band karta hai, isliye close() bhoolne ka dar nahi.
Common mistake: open() ke baad close() bhoolna data save nahi hone ya file lock ka kaaran banta hai. Hamesha with use karo.
Khud try karo: CSV se total nikalo: items aur amounts ki CSV banao, phir DictReader se total jodo.
