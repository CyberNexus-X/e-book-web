Day 3 — input() aur type casting

input() user se data leta hai, par wo hamesha string (text) deta hai. Calculation ke liye use int() ya float() se number me badalna padta hai — isko type casting kehte hain.

Phase: Beginner · Reels: 11/450 – 15/450

Code

age_text = "21"
print(age_text, type(age_text))
age = int(age_text)
print(age, type(age))
print(age + 1)
print(float("3.5"), str(10), bool(""))

Output

21 <class 'str'>
21 <class 'int'>
22
3.5 10 False

Code ki poori detail

  • age_text = "21" — ye text hai, number nahi, chahe dikhne me number lage.
  • int(age_text) — text ko poore number me badalta hai, isliye age ab 21 (int) hai.
  • age + 1 = 22 tabhi hoga jab age number ho; text par + kaam alag karta hai.
  • float("3.5") = 3.5, str(10) = "10" aur bool("") = False hota hai.
  • Asli program me age = int(input("Age? ")) likha jaata hai — input() hamesha str deta hai.
Common mistake: input() ka result seedha + ya - me use mat karo. Pehle int() karo, warna "21" + 1 par TypeError aayega.
Khud try karo: Age calculator banao: age ko int me badlo aur agle saal ki age print karo.
