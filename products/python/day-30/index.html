Day 30 — OOP: class aur object

OOP: Class blueprint hoti hai, object us blueprint se bani asli cheez hoti hai. __init__ constructor hai, self wo object hai jis par method call hua.

Phase: Intermediate · Reels: 146/450 – 150/450

Code

class BankAccount:
    bank = "SBI"

    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    def deposit(self, amt):
        if amt <= 0:
            raise ValueError("amt > 0 chahiye")
        self._balance += amt

    @property
    def balance(self):
        return self._balance

acc = BankAccount("Arhan")
acc.deposit(500)
print(acc.balance, acc.bank)
print(acc.owner)

Output

500 SBI
Arhan

Code ki poori detail

  • class BankAccount: — blueprint banayi, isme bank class variable hai (sab accounts ke liye same).
  • __init__(self, owner, balance=0) — naya account bante hi chalta hai, owner aur balance set karta hai.
  • self — wo object hai jis par method call hua; method me self bhoolna TypeError deta hai.
  • deposit() — balance badhata hai, galat amount (0 ya negative) par ValueError deta hai.
  • @property balance — balance ko attribute jaisa padha ja sakta hai, par seedha set nahi hota (read-only getter).
  • OOP ke 4 pillars: Encapsulation, Abstraction, Inheritance, Polymorphism — aage ke dinon me yehi aayenge.
Common mistake: Method me self bhoolna TypeError deta hai: takes 0 positional arguments but 1 was given. Har method ka pehla parameter self hota hai.
Khud try karo: Car class banao: __init__ me brand/model lo, ek method se car ka intro print karo.
