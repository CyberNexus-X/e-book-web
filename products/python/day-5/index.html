Day 5: Comparison and Logical Operators

Phase: Beginner · Reels: 21/450 – 25/450

Quick Answer

Day 5 teaches comparison and logic. Comparison operators (==, !=, >, <, >=, <=) return True or False, and and, or and not combine conditions. Note: = assigns, == compares.

What You Will Learn

  • x == 7 compares x with 7 and returns True or False. x = 7 only assigns the value.
  • and is True only when both sides are True. or is True when at least one side is True.
  • not flips a value: not True is False.
  • Python allows chaining: 5 < x < 10 means 5 < x and x < 10 together.
  • Falsy values are 0, 0.0, "", [], {}, set() and None. Everything else is truthy, so bool("0") is True.

Code

x = 7
print(x == 7)
print(x != 7)
print(x > 5 and x < 10)
print(x < 5 or x > 10)
print(not (x > 10))
print(5 < x < 10)
print(bool(0), bool(""), bool("0"), bool([]))

Code Explained, Line by Line

  2. and is True only when both sides are True. or is True when at least one side is True.
  3. not flips a value: not True is False.
  4. Python allows chaining: 5 < x < 10 means 5 < x and x < 10 together.
  5. Falsy values are 0, 0.0, "", [], {}, set() and None. Everything else is truthy, so bool("0") is True.
Common Mistake: Writing if x = 5: raises a SyntaxError. Conditions must use ==, not =.

Real-Life Use

Login checks, age gates and discount rules are all built from comparison and logical operators.
