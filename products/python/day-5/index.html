Day 5 — Comparison aur logical operators

Comparison operators (==, !=, >, <, >=, <=) True/False dete hain. Logical operators and, or, not se conditions jodi jaati hain. = assign karta hai, == compare karta hai.

Phase: Beginner · Reels: 21/450 – 25/450

Code

x = 7
print(x == 7)
print(x != 7)
print(x > 5 and x < 10)
print(x < 5 or x > 10)
print(not (x > 10))
print(5 < x < 10)
print(bool(0), bool(""), bool("0"), bool([]))

Output

True
False
True
False
True
True
False False True False

Code ki poori detail

  • x == 7 — compare karta hai, isliye True hai. x = 7 assign karta hai, compare nahi.
  • x > 5 and x < 10 — dono True hon tabhi poora result True hota hai.
  • or me ek bhi True ho to result True hota hai.
  • not ulta kar deta hai: True ka not False hota hai.
  • 5 < x < 10 — chaining hai, matlab 5 < x aur x < 10 dono ek saath check hote hain.
  • Falsy values: 0, 0.0, "", [], {}, set(), None, False. Baaki sab truthy hain, isliye bool("0") True hai.
Common mistake: if x = 5: likhne par SyntaxError aata hai — condition me == use karo, = nahi.
Khud try karo: True ya False batao: 10 > 5 and 10 < 20, aur not (3 == 3) ka answer kya hoga?
