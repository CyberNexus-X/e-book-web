Day 8: if-else

Phase: Beginner · Reels: 36/450 – 40/450

Quick Answer

Day 8 teaches if-else decisions. If the condition is True the if block runs, otherwise the else block runs. Blocks are recognised by 4-space indentation.

What You Will Learn

  • A condition is an expression that is True or False, like marks >= 33.
  • elif means 'otherwise, if': the first True condition in the chain wins and the rest are skipped.
  • else runs only when no condition above it was True.
  • Blocks must be indented, usually by 4 spaces. Wrong indentation raises an IndentationError.
  • "Pass" if marks >= 33 else "Fail" is a one-line if-else, called a ternary expression.

Code

marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 60:
    grade = "B"
else:
    grade = "C"
print(grade)
status = "Pass" if marks >= 33 else "Fail"
print(status)

Output

B
Pass

Code Explained, Line by Line

  1. A condition is an expression that is True or False, like marks >= 33.
  2. elif means 'otherwise, if': the first True condition in the chain wins and the rest are skipped.
  3. else runs only when no condition above it was True.
  4. Blocks must be indented, usually by 4 spaces. Wrong indentation raises an IndentationError.
  5. "Pass" if marks >= 33 else "Fail" is a one-line if-else, called a ternary expression.
Common Mistake: Wrong indentation raises IndentationError. Also note the difference: multiple if statements all run their checks, while an elif chain stops at the first True condition.

Real-Life Use

Pass/fail results, login checks and discount rules are all if-else logic.

Practice Task: Write a program that prints whether a number is big or small, and a login check using username and password.
