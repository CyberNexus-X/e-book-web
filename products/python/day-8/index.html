Day 8 — if-else

if-else se program faisla leta hai. Condition True ho to if wala block chalta hai, warna else wala. Block ko 4 spaces ki indentation se pehchana jaata hai.

Phase: Beginner · Reels: 36/450 – 40/450

Code

marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 60:
    grade = "B"
else:
    grade = "C"
print(grade)
status = "Pass" if marks >= 33 else "Fail"
print(status)

Output

B
Pass

Code ki poori detail

  • marks >= 90 — condition hai, iska answer True ya False hota hai.
  • elif ka matlab 'warna agar' hai — pehla True milte hi chain ruk jaati hai.
  • else tab chalta hai jab upar ki koi condition True na ho.
  • Block ke andar ki lines 4 spaces andar (indented) honi chahiye, warna IndentationError aayega.
  • "Pass" if marks >= 33 else "Fail" — ek line wala if-else hai, isko ternary kehte hain.
Common mistake: Indentation galat ho to IndentationError aata hai. Multiple if sab check hote hain, elif chain me sirf ek chalta hai — farak samajhna zaroori hai.
Khud try karo: Ek program likho jo number bada hai ya chhota, ye bataaye, aur login check (username/password) ka logic banao.
