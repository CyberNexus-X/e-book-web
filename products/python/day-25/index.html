Day 25 — finally, raise, custom errors

else aur finally ke saath, raise se apna error phenka jaata hai aur custom exception banaya jaata hai (Exception class ko inherit karke).

Phase: Intermediate · Reels: 121/450 – 125/450

Code

class AgeError(Exception):
    pass

def set_age(age):
    if age < 0:
        raise AgeError("Age negative nahi")
    return age

try:
    set_age(-5)
except AgeError as e:
    print(e)
print(set_age(21))

Output

Age negative nahi
21

Code ki poori detail

  • class AgeError(Exception) — apni exception class banayi, Exception ko inherit karke.
  • raise AgeError(...) — error ko khud phenkta hai jab age negative ho.
  • except AgeError as e — sirf isi error ko pakadta hai, baaki errors nahi.
  • Original error rakhna ho to raise X from e likha jaata hai.
  • Custom exception ka matlab: error ka naam hi bata de ki galti kya hai.
Common mistake: Error chhupana galat hai — except me pass likh kar error daba dena debugging ko mushkil bana deta hai.
Khud try karo: Age validator banao: negative age par apna error raise karo, sahi age par age return karo.
