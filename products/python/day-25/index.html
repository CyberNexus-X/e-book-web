Day 25: finally, raise, Custom Errors

Day 25 covers else and finally, plus raise and custom exceptions. You raise your own error with raise, and you create a custom exception class by inheriting from Exception.

Phase: Intermediate · Reels: 121/450 – 125/450

Quick Answer

Day 25 covers else and finally, plus raise and custom exceptions. You raise your own error with raise, and you create a custom exception class by inheriting from Exception.

What You Will Learn

  • class AgeError(Exception) creates a custom exception by inheriting from Exception.
  • raise AgeError(...) throws the error yourself when the age is negative.
  • except AgeError as e catches only this error, not other errors.
  • To keep the original error, write raise X from e.
  • A custom exception's name itself explains what went wrong, which makes debugging easier.

Code

class AgeError(Exception):
    pass

def set_age(age):
    if age < 0:
        raise AgeError("Age negative nahi")
    return age

try:
    set_age(-5)
except AgeError as e:
    print(e)
print(set_age(21))

Output

Age negative nahi
21

Code Explained, Line by Line

  1. class AgeError(Exception) creates a custom exception by inheriting from Exception.
  2. raise AgeError(...) throws the error yourself when the age is negative.
  3. except AgeError as e catches only this error, not other errors.
  4. To keep the original error, write raise X from e.
  5. A custom exception's name itself explains what went wrong, which makes debugging easier.
Common Mistake: Hiding an error with except: pass is wrong: it makes debugging much harder because the failure disappears silently.

Real-Life Use

Age checks, payment validation and booking rules use custom exceptions in real apps.

Practice Task: Build an age validator: raise your own error for a negative age, return the age when it is valid.
