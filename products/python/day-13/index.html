Day 13 — List methods

List methods: append end me jodta hai, insert kisi position par, remove value se hatata hai, pop aakhri item nikalta hai, sort list ko hi badal deta hai.

Phase: Beginner · Reels: 61/450 – 65/450

Code

nums = [10, 20, 30]
nums.append(40)
nums.insert(0, 5)
nums.remove(20)
last = nums.pop()
print(nums, "popped:", last)
nums.extend([1, 2])
print(nums)
nums.sort()
print(nums)
print(list(dict.fromkeys([3, 1, 3, 2])))

Output

[5, 10, 30] popped: 40
[5, 10, 30, 1, 2]
[1, 2, 5, 10, 30]
[3, 1, 2]

Code ki poori detail

  • append(40) — end me 40 jodta hai.
  • insert(0, 5) — index 0 par 5 daalta hai, baaki aage khisak jaate hain.
  • remove(20) — value 20 ko hatata hai (pehli baar mili hui).
  • pop() — aakhri item nikal kar wapas deta hai.
  • extend([1, 2]) — do items jodta hai; append([1, 2]) ek list hi jodta (farak samjho).
  • sort() — list ko hi sort karta hai aur None deta hai, isliye nums = nums.sort() galat hai.
  • dict.fromkeys() — duplicates hata kar order bhi banaaye rakhta hai.
Common mistake: nums = nums.sort() likhne par nums None ban jaata hai, kyunki sort() kuch return nahi karta, list ko hi badalta hai.
Khud try karo: Ek list se duplicates hatao aur append vs extend ka farak ek chhote example se samjho.
