Day 17: Dictionary Basics

Day 17 teaches dictionaries. A dictionary stores key-value pairs: you look up a value by its key. The .get() method returns a default value instead of an error when a key is missing.

Phase: Intermediate · Reels: 81/450 – 85/450

Quick Answer

Day 17 teaches dictionaries. A dictionary stores key-value pairs: you look up a value by its key. The .get() method returns a default value instead of an error when a key is missing.

What You Will Learn

  • marks = {"Arhan": 92} creates a dict inside curly brackets, in key: value pairs.
  • marks["Arhan"] returns 92 by looking up the key.
  • marks.get("Aman", 0) returns 0 when the key is missing, instead of raising KeyError.
  • update() adds a new key or changes the value of an existing key.
  • .items() gives key and value together in a loop; list(marks) gives only the keys.

Code

marks = {"Arhan": 92, "Riya": 85}
print(marks["Arhan"])
print(marks.get("Aman", 0))
marks.update({"Riya": 88})
print(marks)
for name, m in marks.items():
    print(name, m)
print(list(marks))

Output

92
0
{'Arhan': 92, 'Riya': 88}
Arhan 92
Riya 88
['Arhan', 'Riya']

Code Explained, Line by Line

  1. marks = {"Arhan": 92} creates a dict inside curly brackets, in key: value pairs.
  2. marks["Arhan"] returns 92 by looking up the key.
  3. marks.get("Aman", 0) returns 0 when the key is missing, instead of raising KeyError.
  4. update() adds a new key or changes the value of an existing key.
  5. .items() gives key and value together in a loop; list(marks) gives only the keys.
Common Mistake: Looking up a missing key directly, like marks["Aman"], raises KeyError. The safe way is .get().

Real-Life Use

Phonebooks, user profiles and JSON data from APIs are all dictionaries.

Practice Task: Make a student marks dict and a phonebook dict (name to number).
