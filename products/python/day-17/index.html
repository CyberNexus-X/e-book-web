Day 17 — Dictionary basics

Dictionary key-value pairs rakhta hai: key se value milti hai. .get() se missing key par error nahi aata, balki default value milti hai.

Phase: Intermediate · Reels: 81/450 – 85/450

Code

marks = {"Arhan": 92, "Riya": 85}
print(marks["Arhan"])
print(marks.get("Aman", 0))
marks.update({"Riya": 88})
print(marks)
for name, m in marks.items():
    print(name, m)
print(list(marks))

Output

92
0
{'Arhan': 92, 'Riya': 88}
Arhan 92
Riya 88
['Arhan', 'Riya']

Code ki poori detail

  • marks = {...} — curly brackets me dict banta hai, key: value ke jode me.
  • marks["Arhan"] = 92 — key se value milti hai.
  • marks.get("Aman", 0) = 0 — key na mile to KeyError ki jagah default (0) milta hai.
  • update() — nayi key jodta ya purani ki value badalta hai.
  • .items() — key aur value dono ek saath loop me deta hai; list(marks) sirf keys deta hai.
Common mistake: Missing key ko seedha marks["Aman"] se maangne par KeyError aata hai. Safe tareeka .get() hai.
Khud try karo: Student marks dict banao aur ek phonebook dict banao (naam → number).
