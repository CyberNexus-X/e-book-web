Day 7 — f-strings aur slicing

f-string se variables ko text ke andar seedha likha jaata hai. Slicing [start:end:step] se string ka hissa nikala jaata hai. Index 0 se start hota hai.

Phase: Beginner · Reels: 31/450 – 35/450

Code

name = "Arhan"
score = 92.456
s = "python"
print(f"{name}: {score:.1f}%")
print(f"{name=}")
print(s[0], s[-1])
print(s[0:3])
print(s[::2])
print(s[::-1])

Output

Arhan: 92.5%
name='Arhan'
p n
pyt
pto
nohtyp

Code ki poori detail

  • f"{name}: {score:.1f}%" — f-string me {} ke andar variable likha jaata hai, :.1f ka matlab 1 decimal tak dikhao.
  • f"{name=}" — variable ka naam aur value dono dikhata hai, debugging me kaam aata hai.
  • s[0] = 'p' (pehla letter), s[-1] = 'n' (aakhri letter) — index 0 se start hota hai.
  • s[0:3] = 'pyt' — end wali position (3) shamil nahi hoti.
  • s[::2] har doosra letter leta hai, aur s[::-1] poori string ulta kar deta hai.
Common mistake: Index 0 se start hota hai, 1 se nahi. s[1] = 'y' hai, 'p' nahi.
Khud try karo: Kisi string ko reverse karo — s[::-1] use karo aur samjho ki step -1 peeche se aage chalata hai.
