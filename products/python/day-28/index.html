Day 28 — Modules

Modules dusri files ka code hote hain: import math, random se unke functions milte hain. Apni file ka naam kabhi random.py ya math.py mat rakho, warna asli module chhup jaata hai.

Phase: Intermediate · Reels: 136/450 – 140/450

Code

import math, random
print(math.pi > 3, math.sqrt(16))
random.seed(0)
dice = random.randint(1, 6)
print(dice)
otp = "".join(random.choices("0123456789", k=6))
print(len(otp))
print(otp)
if __name__ == "__main__":
    print("Direct run pe hi")

Output

True 4.0
4
6
742547
Direct run pe hi

Code ki poori detail

  • import math — math module ke functions (pi, sqrt) mil jaate hain.
  • random.randint(1, 6) — 1 se 6 tak ka random number (dice) deta hai.
  • random.seed(0) — is example me output ko repeatable banata hai, taaki har baar wahi dice/OTP pattern samajh aaye (asli program me seed mat lagao).
  • random.choices(..., k=6) — 6 random digits lekar OTP jaisa string banata hai.
  • if __name__ == "__main__" — ye block sirf tab chalta hai jab file seedha chalayi jaaye, import karne par nahi.
Common mistake: Apni file ka naam random.py / math.py mat rakho — Python tumhari file ko asli module samajh lega aur asli module chhup jayega.
Khud try karo: Dice roller banao (randint se) aur OTP generator banao (choices se).
