Day 18 — Dict methods aur loops

Dict methods: keys(), values(), items() se keys, values ya dono milte hain. Loop chalte hue dict me add/delete karna error deta hai — pehle list() banao.

Phase: Intermediate · Reels: 86/450 – 90/450

Code

marks = {"Arhan": 92, "Riya": 85, "Aman": 78}
print(list(marks.keys()))
print(list(marks.values()))
print(list(marks.items()))
count = {}
for w in "to be or not to be".split():
    count[w] = count.get(w, 0) + 1
print(count)
print(count["to"])

Output

['Arhan', 'Riya', 'Aman']
[92, 85, 78]
[('Arhan', 92), ('Riya', 85), ('Aman', 78)]
{'to': 2, 'be': 2, 'or': 1, 'not': 1}
2

Code ki poori detail

  • .keys() — saari keys, .values() — saari values, .items() — (key, value) jode deta hai.
  • count.get(w, 0) + 1 — word count ka standard pattern hai: pehli baar 0 se start, phir +1.
  • Python 3.7+ me dict insertion order yaad rakhta hai — jis order me daala, usi order me milta hai.
  • Loop ke dauran dict badalne par RuntimeError aata hai; zaroorat ho to list(d) par loop karo.
Common mistake: Loop chalate hue dict me add/delete mat karo — pehle keys ki list banao, phir badlo.
Khud try karo: Kisi sentence ka word count nikalo (dict + .get() pattern se).
