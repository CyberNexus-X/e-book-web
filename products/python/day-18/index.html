Day 18: Dict Methods and Loops

Day 18 covers dict methods: keys() gives all keys, values() gives all values, and items() gives (key, value) pairs. Never add or delete keys while looping over a dict, or you get a RuntimeError.

Phase: Intermediate · Reels: 86/450 – 90/450

Quick Answer

Day 18 covers dict methods: keys() gives all keys, values() gives all values, and items() gives (key, value) pairs. Never add or delete keys while looping over a dict, or you get a RuntimeError.

What You Will Learn

  • .keys() returns all keys, .values() returns all values, .items() returns (key, value) pairs.
  • count.get(w, 0) + 1 is the standard word-count pattern: start from 0 on first sight, then add 1.
  • Since Python 3.7, dicts remember insertion order: items come out in the order they were added.
  • Changing a dict during a loop raises RuntimeError. Loop over list(d) if you must change it.

Code

marks = {"Arhan": 92, "Riya": 85, "Aman": 78}
print(list(marks.keys()))
print(list(marks.values()))
print(list(marks.items()))
count = {}
for w in "to be or not to be".split():
    count[w] = count.get(w, 0) + 1
print(count)
print(count["to"])

Output

['Arhan', 'Riya', 'Aman']
[92, 85, 78]
[('Arhan', 92), ('Riya', 85), ('Aman', 78)]
{'to': 2, 'be': 2, 'or': 1, 'not': 1}
2

Common Mistake: Do not add or delete keys while looping over a dict. Make a list of keys first, then change the dict.

Real-Life Use

Word counts, vote counts and frequency tables all use this dict pattern.
