Day 1 — Pehla program

Pehla din, pehli line. print() screen par kuch dikhata hai, variable naam wala dabba hota hai, aur # wali line ko Python ignore karta hai.

Phase: Beginner · Reels: 1/450 – 5/450

Code

name = "Arhan"
lang = "Python"
# Ye line comment hai, Python isko nahi chalata
print("Hello Duniya")
print("Mera naam", name, "hai")
print(name, "seekh raha hai", lang)

Output

Hello Duniya
Mera naam Arhan hai
Arhan seekh raha hai Python

Code ki poori detail

  • name = "Arhan" — ek variable banaya, jisme text (string) rakha gaya.
  • lang = "Python" — doosra variable, isme language ka naam hai.
  • # wali line comment hai — ye sirf insaan ke padhne ke liye hai, Python isko skip karta hai.
  • print() brackets ke andar di hui cheez ko screen par dikhata hai.
  • print me comma se alag-alag cheezein ek line me, space ke saath, print ho jaati hain.
Common mistake: Variable ka naam number se start nahi hota (1name galat hai) aur Python case-sensitive hai — Name aur name alag variables hain.
