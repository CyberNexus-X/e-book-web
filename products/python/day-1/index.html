Day 1: First Program

Day 1 teaches your first Python program: print() shows text on screen, a variable stores a value under a name, and a line starting with # is a comment that Python ignores.

Phase: Beginner · Reels: 1/450 – 5/450

Quick Answer

Day 1 teaches your first Python program: print() shows text on screen, a variable stores a value under a name, and a line starting with # is a comment that Python ignores.

What You Will Learn

  • A variable is a named box: name = "Arhan" stores the text Arhan under the name name.
  • print() displays whatever is inside its brackets on the screen.
  • A line starting with # is a comment. It is only for humans to read; Python skips it completely.
  • print() can show several things at once: print(name, "is learning") joins them with a space.
  • Python is case-sensitive: Name and name are two different variables.

Code

name = "Arhan"
lang = "Python"
# This is a comment, Python ignores it
print("Hello World")
print("My name is", name)
print(name, "is learning", lang)

Output

Hello World
My name is Arhan
Arhan is learning Python

Code Explained, Line by Line

  1. A variable is a named box: name = "Arhan" stores the text Arhan under the name name.
  2. print() displays whatever is inside its brackets on the screen.
  3. A line starting with # is a comment. It is only for humans to read; Python skips it completely.
  4. print() can show several things at once: print(name, "is learning") joins them with a space.
  5. Python is case-sensitive: Name and name are two different variables.
Common Mistake: A variable name cannot start with a number (1name is invalid), and = assigns a value while == compares two values. Mixing them up is the most common Day 1 error.

Real-Life Use

Every program you will ever write starts here: showing output, storing data in variables, and leaving comments for other developers.

Practice Task: Store your name and your favourite language in two variables and print them both in one line.
